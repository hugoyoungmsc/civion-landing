Verification

Last updated: 25 November 2026

Civion publishes what it checks, how each result was verified, and what it does not do. The calculation report carries the clause, equation and inputs behind every governing result; this page records the wider verification basis.

Verification sources

  • EN 1992-1-1:2004, the governing code text.
  • The ICE Designers' Guide to EN 1992-1-1 and EN 1992-1-2.
  • The blog's worked examples, each with a clause-by-clause verification record and a free workbook. Check the method there before trusting the tool.

Not covered yet

  • UK National Annex; the current routes are CEN and the French NA.
  • Continuous beams and redistribution; the beam module is simply supported.
  • Calculated deflection (§7.4.3); the simplified §7.4.2 check only.
  • Column detailing checks (9.5.2 / 9.5.3).
  • Torsion, punching shear, slabs, footings, walls, fire and seismic design.
  • Nominal-stiffness second-order analysis; the column uses nominal curvature.

How to reproduce

Every published example shows the intermediate values, the clause references and a downloadable workbook. Start with the worked examples, then compare the result with the tool.

Every result must be independently verified by a qualified engineer for the specific project. Civion does not certify or stamp designs.
